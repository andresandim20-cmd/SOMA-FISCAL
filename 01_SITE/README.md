# ST BIKE — Painel de Consulta (GitHub Pages)

## Publicação

1. No GitHub, crie um repositório público, por exemplo `st-bike-consulta`.
2. Envie **todo o conteúdo desta pasta** à raiz do repositório: `index.html`, `style.css`, `app.js`, `dados.json`, `documentos.json` e a pasta `pdfs/`.
3. Abra **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Escolha `main`, pasta `/ (root)` e clique em **Save**.
5. A página estará disponível na URL indicada pela seção Pages, no formato `https://SEU-USUARIO.github.io/st-bike-consulta/`.

## Edição

Os parâmetros estão em `dados.json`. Os links para PDFs apontam para os arquivos locais do repositório. Os 37 PDFs estão incluídos.

## Limitações

Os parâmetros foram preservados **conforme a planilha enviada**, incluindo fórmulas textuais e valores não verificados. Não há certificação de vigência, benefício, responsabilidade por ST ou aplicação ao caso concreto. Os documentos foram associados por tema/UF, e não por uma validação artigo-a-artigo. Alguns PDFs podem conter legislação extensa; use a pesquisa do leitor para localizar o artigo citado.

Esta é uma interface de consulta, não um motor de cálculo nem parecer tributário.
